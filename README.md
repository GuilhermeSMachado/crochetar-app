# 🧶 Crochetar

Aplicativo Android desenvolvido para organização e visualização de receitas de crochê de forma simples, moderna e intuitiva.

## ✨ Funcionalidades

- 📋 Listagem de receitas
- ➕ Cadastro de novas receitas
- 🖼 Inserção de imagens
- ⭐ Sistema de favoritos
- 🔎 Pesquisa de receitas
- 🧵 Filtro por categorias
- ✏️ Edição de receitas
- 🗑 Exclusão de receitas
- 💾 Persistência local de dados
- 🎨 Interface personalizada inspirada em artesanato

## 📱 Tecnologias utilizadas

- Kotlin
- Android Studio
- RecyclerView
- CardView
- Material Design
- SharedPreferences

## 🎨 Design

O aplicativo utiliza identidade visual própria desenvolvida no Figma, com foco em uma experiência acolhedora e artesanal.

## 🚀 Objetivo

O projeto foi desenvolvido com fins acadêmicos e de aprendizado em desenvolvimento Android nativo utilizando Kotlin.
